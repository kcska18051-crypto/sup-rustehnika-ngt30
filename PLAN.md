# Рустехника — страница товара

Основа: сохранённая разметка одной страницы и оригинальные ресурсы. Без других страниц, аналитики и отправки заявок на рабочий сайт клиента.

1. Сохранить оригинальные HTML, CSS, изображения и шрифты; восстановить локальные взаимодействия галереи, количества, избранного, корзины и форм.
2. Заменить вкладки последовательными разделами с постоянными якорями и ссылками у всех заголовков. Единый line-height 1.5 для текста и 1.3 для заголовков.
3. Отзывы: оригинальный жёлтый #ffba08, белый и серый; четыре карточки на компьютере, две на планшете, одна на телефоне. После четырёх — стрелки и движение по одной карточке. Скрытие текста после четырёх строк, раскрытие «Читать весь отзыв». Образцы явно демонстрационные, редактируются в reviews.json. Реальный отзыв пока не предоставлен.
4. Проверить якоря, длинные отзывы, шаг карусели, количество 0/1/4/5, формы, галерею и мобильную ширину. Подготовить README с границами серверных функций. Загрузить в отдельный GitHub-репозиторий.

Серверные операции оригинального Bitrix невозможно перенести из публичной страницы; локальные формы сохраняют демонстрационные данные только в браузере и прямо сообщают об этом.
