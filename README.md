# SUP — Рустехника / NORDBERG NGT30

Копия одной детальной страницы с оригинальными ресурсами и точечными изменениями. Другие страницы не скопированы; переходы на них заблокированы.

## Запуск

Нужен Node.js 18 или новее. Зависимости не требуются.

```sh
node server.mjs
```

Открыть http://127.0.0.1:4173 . Статические файлы можно разместить на любом HTTP-хостинге. Открывать через `file://` не нужно: браузер блокирует загрузку JSON.

## Что изменено

- Все разделы доступны одновременно. Меню содержит обычные ссылки `#description`, `#characteristics`, `#equipment`, `#instructions`, `#reviews`. У заголовков есть собственные ссылки, якоря учитывают закреплённое меню.
- Единый межстрочный интервал: 1.5 для текста, 1.3 для заголовков.
- Четыре отзыва на компьютере, два на планшете, один на телефоне. Стрелки двигают ряд по одному отзыву, ползунка и точек у отзывов нет. После четырёх строк — «Читать весь отзыв» / «Свернуть». Без рейтинга, дат и звёзд.
- Выделение выбранного отзыва: оригинальный жёлтый `#ffba08`, серая подложка. Остальные цвета и исходные шрифты взяты с сайта клиента.
- Галерея с увеличением, количество, избранное, демонстрационная корзина и локальное добавление отзывов.

## Реальные отзывы

Редактировать `reviews.json`: `name`, `text`, необязательные `featured: true` для выделения и `demo: true` для демонстрационных записей. Сейчас все шесть записей — явно подписанные примеры для проверки карусели. Настоящие имя и текст клиента не предоставлены. Для реальных отзывов удалить `demo` и заменить содержимое. Пустой массив показывает пустое состояние.

## Границы функциональности

Форма отзыва поддерживает выбор нескольких изображений, повторное добавление и удаление перед отправкой. Ограничения на количество файлов в интерфейсе нет. В карточке отображаются первые три миниатюры; последняя показывает `+N`, если есть дополнительные фото. Просмотр открывает все изображения, со стрелками, клавишами влево/вправо, счётчиком и лентой миниатюр. Файлы сохраняются как Blob в IndexedDB, а ссылки на них — в локальном отзыве; они доступны после обновления в том же браузере и на том же домене. Код находится в `review-photos.js`. Для рабочего сайта потребуется серверное хранилище и API загрузки. Фактическая ёмкость ограничена доступным браузеру местом, а не количеством картинок в компоненте.

Это автономная клиентская копия, а не перенос сервера Bitrix. Оформление заказов, вход в аккаунт, доставка, поиск по каталогу, платежи, чаты и отправка заявок требуют доступа к API клиента. Корзина, избранное, отзывы и формы сохраняются только в localStorage данного браузера. Формы явно сообщают, что не отправляют заявку. Финансовые предложения открывают демонстрационную форму; расчёт кредита не подключён. Никакие заявки не уходят на рабочий сайт клиента. Исходная аналитика и сторонние виджеты не запускаются.

Публичные PDF из карточки используются как документы, а не как копии других страниц. Расхождение «220 В» в исходном описании и «380 В» в названии сохранено: исправление технических данных требует подтверждения клиента.

## Файлы

- `index.html` — исходная разметка с подключёнными изменениями.
- `original.html` — сохранённая разметка для сравнения (без оригинальных серверных скриптов).
- `app.js`, `changes.css` — новые взаимодействия и стили.
- `assets/`, `asset-manifest.json` — локальные оригинальные ресурсы и их источники.
- `QA.md` — результаты проверок.

Размещение на рабочем Bitrix: перенести якорную структуру, стили и логику отзывов в шаблон компонента; реальные серверные обработчики корзины и форм оставить из проекта клиента. Демо-обработчики из `app.js` в рабочий магазин не переносить.
